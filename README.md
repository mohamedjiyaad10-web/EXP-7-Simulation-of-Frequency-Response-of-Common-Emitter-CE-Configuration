# EXP-7-Simulation-of-Frequency-Response-of-Common-Emitter-CE-Configuration

Aim
To design and simulate the frequency response of a Common Emitter (CE) configuration circuit using LTspice.
Software Required
•	LTspice 
Procedure
1.	Double-click on the LTspice icon. 
2.	Open a New Schematic window. 
3.	Pick and place the required components from the library and draw the circuit diagram. 
4.	Complete the connections. Right-click on the components and modify the required component values. 
5.	Save the file by giving an appropriate file name. 
6.	Click on the Run option → Advanced → select AC Analysis → enter the required amplitude, time delay and step-time values. 
7.	Click on the Run option → open the Simulation Window → place the probe to obtain the output graph.
